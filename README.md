# Universal Markdown Documentation Approach

UMDA — это методология и набор инструментов для создания Markdown-документации с Unicode-расширяемой нотацией, которую можно собирать разными сборщиками. 

Идея в том, что разные сборщики документации используют разную нотацию для переменных, блоков вставки кода, операторов условий. У сборщиков разные конфигурационные файлы и разные форматы файла с навигацией. UMDA призвана всё стандартизировать.

Вы просто используете интуитивно понятную нотацию вместе с Markdown для расширения его возможностей, а UMDA сама подготовит Markdown к сборке. Так исходники документации остаются чистыми, легко читаются и могут быть адаптированы под разный стек. 

Например, UMDA превращают Unicode-нотацию `ℹ️ "Зависимость от прав групп"` в `!!! note "Зависимость от прав групп"`, понятную для MkDocs. Или можно вместо громоздкого admonition warning в MkDocs-стиле `!!! warning "Ограничения возможностей прав"` использовать Unicode-нотацию: `⚠️ "Ограничения возможностей прав"`.
 
В основе UMDA лежит одна простая мысль: чем проще, тем лучше, понятнее и надёжнее.

Сейчас поддерживаются два сборщика: VuePress и MKdocs.
